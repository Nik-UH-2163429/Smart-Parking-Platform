# HW3 - Agile, Scrum, and Kanban

## Smart Parking Platform

This assignment applies Agile and Scrum concepts to the Smart Parking Platform project.

### Product Backlog

The product backlog was created in Trello and contains 45 backlog items divided into the following categories:

- Login: 5 items
- User and Operator UI: 15 items
- User and Operator Backend Processes: 15 items
- User and Operator Reporting: 10 items

### Sprint 1

Sprint 1 focuses on establishing the account authentication functionality for the Smart Parking Platform.

The Sprint 1 backlog includes:

- User Account Registration
- Operator Account Registration
- User Login
- Operator Login
- Forgot / Reset Password
- User Authentication Service
- Operator Authentication Service
- Account Creation API
- Password Reset Service
- User Dashboard
- Operator Dashboard
