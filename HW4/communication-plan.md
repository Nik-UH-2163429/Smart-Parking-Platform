# Smart Parking Platform - Communication Plan

## Purpose

The purpose of this communication plan is to establish how the Smart Parking Platform team will communicate project progress, risks, issues, and important decisions. Consistent communication will help the team stay organized and ensure that stakeholders remain informed throughout the project.

## Meeting Cadence

| Meeting | Participants | Frequency | Purpose |
|---|---|---|---|
| Team Check-In | Project Team | Weekly | Review completed work, current tasks, blockers, and upcoming responsibilities. |
| Development Review | Development Team | Weekly | Discuss technical progress, bugs, testing, and integration issues. |
| Project Progress Review | Project Team | Biweekly | Review milestones, schedule progress, risks, and changes to project priorities. |
| Stakeholder Update | Project Team and Stakeholders | Weekly | Present project progress, completed work, current risks, and next steps through the stakeholder update video. |

## Reporting Methods

### GitHub

GitHub will serve as the primary location for project documentation, source code, assignments, and version control. Team members will use commits and repository updates to document project progress.

### Weekly Stakeholder Video

A short stakeholder update video will be created each week. The video will summarize:

- Work completed during the week
- Current project status
- Problems or risks encountered
- Work planned for the next week

### Project Documentation

Project requirements, schedules, risk information, and other important project documents will be maintained in the GitHub repository so that team members can access the most recent information.

### Team Communication

Team members will communicate directly when questions, blockers, or urgent issues arise rather than waiting until the next scheduled meeting.

## Communication Responsibilities

The project team is responsible for keeping assigned tasks and documentation current. Important changes, delays, technical problems, or risks should be communicated to the team as soon as they are identified.

The project manager is responsible for monitoring overall project progress, coordinating meetings, reviewing risks, and ensuring that stakeholders receive regular project updates.
