# HW6 – Tools and Technology: Project Updates

## Smart Parking Platform

**Course:** CIS 4374 / TLIM 3355  
**Assignment:** Homework 6  
**Topic:** Project Documentation Review and Updates

## Overview

This assignment focuses on reviewing and updating existing project management documentation for the Smart Parking Platform.

The goal is to ensure that project requirements, schedules, resources, costs, risks, and responsibilities remain accurate and consistent with the project's current development plans.

## Documents to Review

- Software Requirements Specification (SRS)
- User Stories
- Work Breakdown Structure (WBS)
- Project Timeline and Gantt Charts
- Product Backlog
- Sprint Planning and Jira/Trello Screenshots
- Risk Register
- Communication Plan
- Project Roles
- Cost Management Plan
- RACI Matrix

## Project Management Approach

GitHub serves as the central repository for project documentation and version control. Existing project management artifacts will be reviewed and updated to maintain consistency across the Smart Parking Platform.
