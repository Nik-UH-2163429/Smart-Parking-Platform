## 6. GitHub and Project Tracking Responsibilities

Following the transition away from Trello, the project team will maintain planning documentation in GitHub.

Responsibilities include:

- **Project Manager:** Maintain project plans, priorities, documentation updates, and stakeholder reports.
- **Software Developer:** Record development progress and relevant source code changes.
- **UI/UX Designer:** Maintain interface design documentation and usability updates.
- **QA Tester:** Document testing results and identified defects.
- **DevOps Engineer:** Maintain deployment configurations and support version control workflows.

The team will use descriptive commit messages to document project changes.
