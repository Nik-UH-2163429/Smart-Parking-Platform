# HW5 — RACI Matrix

## 1. Project Overview

The Smart Parking Platform is a software-based system designed to help drivers locate available parking spaces, view parking availability, and improve parking management efficiency.

This RACI matrix establishes clear responsibilities for the project team during planning, design, development, testing, and deployment.

The matrix is based on the fictional team roles established in the HW5 Resource Plan.

## 2. RACI Definitions

RACI is a responsibility assignment framework used to clarify team member involvement in project activities.

- **R — Responsible:** Performs the work required to complete the task.
- **A — Accountable:** Ultimately answerable for the task and approves the deliverable.
- **C — Consulted:** Provides expertise, feedback, or input before decisions are made.
- **I — Informed:** Receives updates about progress or decisions.

Each project activity has exactly one Accountable team member to ensure clear ownership.

## 5. Responsibility Assignment Explanation

## 6. RACI Management Strategy

The project team will use the RACI matrix throughout the development lifecycle to clarify responsibilities and reduce confusion.

The Project Manager will review assignments during weekly team meetings and update the matrix when responsibilities change.

The team will follow these guidelines:

1. Each activity must have exactly one Accountable team member.
2. Every activity must have at least one Responsible team member.
3. Consulted team members should provide input before major decisions.
4. Informed team members should receive relevant updates.
5. Responsibility changes must be documented and communicated.

## 7. Conclusion

The RACI matrix establishes clear accountability and responsibility for the Smart Parking Platform.

By defining the roles of the Project Manager, Software Developer, UI/UX Designer, QA Tester, and DevOps Engineer, the team can coordinate work more effectively, improve communication, and reduce project management risks.

This responsibility structure supports the successful completion of the project within its planned 12-week schedule and estimated $35,365 budget.
