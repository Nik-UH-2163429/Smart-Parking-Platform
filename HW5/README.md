# HW5 — Resource & Cost Management

## Smart Parking Platform

This assignment presents the resource and cost management plan for the Smart Parking Platform project.

The plan includes:

1. **Roles and Resources:** Project team members, fictional names, skill levels, responsibilities, and estimated resource allocations.
2. **Resource and Cost Plan:** Bottom-up cost estimates, labor and infrastructure expenses, contingency funding, and a monthly cashflow budget.
3. **RACI Matrix:** Assignment of Responsible, Accountable, Consulted, and Informed roles for major project activities.

All staffing rates, allocations, and financial estimates are hypothetical and are intended for academic project planning purposes.
