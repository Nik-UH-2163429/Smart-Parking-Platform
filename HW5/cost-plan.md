# HW5 — Cost Management Plan

## 1. Project Overview

The Smart Parking Platform is a software solution designed to help drivers locate available parking spaces, monitor parking availability, and improve parking management efficiency.

This cost management plan estimates the resources and expenses required to complete the project over a 12-week (three-month) development period.

All costs are hypothetical estimates for academic planning purposes.

## 2. Cost Estimation Method

The project uses the **bottom-up cost estimation method**.

Bottom-up estimation calculates the expected cost of each resource or activity individually and then combines these amounts to determine the total project budget.

This approach is appropriate because the project has defined team roles, estimated working hours, and identifiable infrastructure expenses.

**Formula:**

Estimated Labor Cost = Estimated Hours × Hourly Rate

Total Project Budget = Labor + Infrastructure + Tools + APIs + Contingency

## 5. Contingency Reserve

A contingency reserve of 10% is included to account for identified project uncertainties, such as:

- Unexpected cloud hosting expenses.
- Additional software testing requirements.
- API usage exceeding estimates.
- Minor development delays or rework.

**Calculation:**

Subtotal = $31,200 + $950 = $32,150

Contingency = $32,150 × 0.10 = $3,215

## 8. Cost Monitoring and Control

The Project Manager will monitor project expenses weekly and compare estimated costs with actual expenditures.

Cost management activities will include:

1. Reviewing labor hours and resource utilization.
2. Monitoring cloud hosting and database expenses.
3. Tracking third-party API usage.
4. Evaluating budget variances.
5. Approving additional expenditures before implementation.
6. Updating budget forecasts when project requirements change.

Any significant budget changes will be documented and communicated to project stakeholders.

## 9. Cost Management Conclusion

The Smart Parking Platform has an estimated development budget of **$35,365**, including a 10% contingency reserve.

The bottom-up estimation method provides a clear breakdown of labor, infrastructure, software, and operational costs.

Regular expense monitoring and budget reviews will help the project team manage financial risks and maintain control over project spending.
